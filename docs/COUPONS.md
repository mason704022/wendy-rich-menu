# 折扣券管理說明

管理員可在 LIFF 管理後台建立折扣券、指派給特定會員（例如舊生）。會員在購課頁選用後，訂單會記錄原價、折扣與實付金額。

## 進入管理後台

```
https://liff.line.me/{LIFF_ID}?page=admin
```

登入帳號須與 `ADMIN_LINE_USER_ID` 一致。

## 建立折扣券

1. 開啟 **折扣券** 分頁
2. 填寫：
   - **券名稱**：例如「舊生回饋 500 元」
   - **折扣類型**：固定金額 或 百分比
   - **數值**：固定金額填 NT$，百分比填 1–100
   - **到期日**（選填）
   - **適用方案**（不勾 = 全部方案）
3. 按 **建立券模板**

## 指派給舊生

1. 在 **指派給會員** 區塊選擇券模板
2. 勾選 **僅顯示曾購課會員（舊生）** 可快速篩選
3. 搜尋姓名或電話，點選會員
4. 按 **指派折扣券**（系統會自動 LINE 通知會員）

## 會員如何使用

1. 開啟 Rich Menu → **購買課程**
2. 選擇方案後，若有可用券會出現 **折扣券** 下拉選單
3. 選券後顯示原價、折抵、實付金額
4. 依 **實付金額** 匯款並完成通知

## 確認匯款

**待確認匯款** 分頁會顯示：

- 實付金額（管理員對帳依此金額）
- 原價、折扣、券名稱（若有使用）

確認後折扣券標記為 **已使用**；拒絕訂單則券釋回 **可用**。

## 撤回折扣券

在 **指派紀錄** 中，狀態為 **可用** 的券可按 **撤回** 刪除指派。

## 折扣規則

| 類型 | 計算方式 |
|------|----------|
| 固定金額 | 折抵 min(設定值, 原價-1)，至少付 1 元 |
| 百分比 | floor(原價 × 百分比 / 100)，至少付 1 元 |

折扣**不影響堂數**，僅影響匯款金額。

## Google Sheets

若已啟用 Sheets 同步，匯款訂單 tab 會新增欄位：原價、折扣、實付金額、折扣券名稱。

## API 摘要（開發參考）

| 端點 | 說明 |
|------|------|
| `GET /api/purchases/coupons/:lineUserId?planId=` | 會員可用券 |
| `POST /api/purchases/coupons/preview` | 預覽折後價 |
| `POST /api/purchases/` | 可帶 `couponAssignmentId` |
| `GET/POST /api/admin/coupons/templates` | 券模板 |
| `GET/POST/DELETE /api/admin/coupons/assignments` | 指派管理 |
| `GET /api/admin/members/search?q=&onlyWithPurchase=` | 搜尋會員 |

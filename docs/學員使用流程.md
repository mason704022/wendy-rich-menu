# 學員使用流程說明

**品牌：** 藏在咖啡廳裡的畫畫課  
**使用方式：** 透過 LINE 官方帳號選單進入各功能頁面

---

## 一、第一次來？建議順序

```
加入好友 → 看課程資訊 → 註冊會員 → 購買堂數 → 預約上課 → 收到開班通知 → 到回咖啡上課
```

---

## 二、加入 LINE 好友

1. 掃描或搜尋官方帳號，點 **加入好友**。
2. 系統會自動發送歡迎訊息，介紹如何從下方選單開始使用。
3. 點開 Rich Menu（圖文選單）即可進入各項功能。

---

## 三、課程資訊（選單：課程資訊）

適合還在考慮、想先了解再報名的人。

- **認識我們**：課程理念、上課方式、地點（回咖啡）、交通與停車。
- **常見問題**：幾人開班、可預約多久、取消規定等。
- 不需註冊即可瀏覽。

---

## 四、會員註冊

**什麼時候需要？**  
第一次要 **購買課程** 或 **預約上課** 時，若尚未註冊會跳出註冊畫面。  
也可從 **會員資訊** 進入註冊。

**要填什麼？**

| 項目 | 說明 |
|------|------|
| LINE ID | 在 LINE 內開啟時會自動帶入，不用自己查 |
| 姓名 | 必填 |
| 年齡、職業、居住地 | 必填（選「其他」時要補充說明） |
| 手機 | 必填，一個手機只能綁定一個 LINE 帳號 |

**注意：**

- 若顯示「手機已被註冊」，請用當初註冊的那個 LINE 帳號登入，或確認手機是否填錯。
- 註冊完成後才能購課與預約。

---

## 五、購買課程（選單：購買課程）

**流程：**

1. 選擇方案（例如：體驗 1 堂、五堂、八堂等）。
2. 閱讀並同意 **購課條款**。
3. 若有工作室發給的 **折扣券**，可在此選用。
4. 依畫面指示 **匯款**，並填寫匯款人姓名、帳號後五碼等資料。
5. 送出後狀態為「等待確認」；工作室核對匯款後會 **以 LINE 通知你**，並將堂數加入帳戶。
6. 收到確認訊息後，即可前往預約。

**提醒：** 在匯款確認前，帳戶還不會有可用堂數，無法完成正取預約（需有剩餘堂數）。

---

## 六、預約上課（選單：預約上課）

**前提：** 已註冊，且帳戶有 **剩餘堂數**（備取另見下方說明）。

**流程：**

1. 選擇 **日期**（可預約範圍：從今天起算 **14 天** 內）。
2. 選擇 **時段**（固定為每週三、五、六等開課時段，以畫面顯示為準）。
3. 閱讀 **訂課須知**。
4. 查看該堂／該週的 **課程主題**（若工作室已上架）。
5. 選擇 **飲品**（及冷熱，若該品項有選項）。
6. 確認送出 → 你會收到 **LINE 預約成功通知**（僅通知本人）。

**名額怎麼算？**

| 狀態 | 說明 |
|------|------|
| 正取 | 名額內成功預約，**先扣 1 堂** |
| 備取 | 正取已滿時可排候補，**先不扣堂**；若有人取消釋出名額，依序遞補為正取並扣堂 |

每堂 **正取最多 10 人**，**備取最多 2 人**。

---

## 七、什麼時候算「確定開班」？

- 每堂課在 **開課前 24 小時** 為預約／取消截止點（截止前仍可預約或取消；截止後不行）。
- **截止之後**，若該堂 **正取滿 5 人（含）以上**，工作室會以 LINE 通知 **確定開班**（日期、時間、地點：新竹回咖啡、入場與停車說明、你的飲品等）。
- 若 **不足 5 人**，該堂 **不開班**；你會收到通知，**已扣的堂數會退回**，該次預約亦會取消。

**提醒：** 收到「預約成功」≠ 當下已確定開班；請留意截止後的開班／不開班通知。

---

## 八、取消預約

1. 至 **會員資訊** 查看你的預約。
2. 在 **開課前 24 小時之前** 可取消。
3. **正取** 取消後，**1 堂會退回** 帳戶；若有人候補，系統可能將備取學員遞補為正取。
4. 開課前 24 小時內 **無法** 線上取消（有特殊狀況請私訊工作室）。

---

## 九、會員資訊（選單：會員資訊）

你可以：

- 查看 **剩餘堂數**、購課紀錄摘要。
- 查看 **近期預約**。
- 查看可用的 **折扣券**（購課時使用）。
- **編輯** 姓名、手機、年齡、職業、居住地。
- 查看自己的 **LINE ID**。

---

## 十、上課當天

- **地點：** 新竹市回咖啡（詳細地址見課程資訊／開班通知）。
- **入場：** 開課前約 **20 分鐘** 可入場。
- **停車：** 附近有可停汽機車的區域（見課程說明或開班通知）。
- **飲品：** 預約時已選的飲品，教室會依統計準備（請以開班通知為準）。

---

## 十一、你會收到的 LINE 通知（學員）

| 時機 | 內容 |
|------|------|
| 加入好友 | 歡迎與選單使用說明 |
| 預約成功 | 時段、正取或備取、飲品、後續開班說明 |
| 購課匯款確認／未通過 | 堂數是否入帳或需重新聯繫 |
| 派發折扣券 | 券的名稱與使用方式（若有） |
| 截止後確定開班 | 日期、時間、地點、飲品與上課提醒 |
| 截止後不開班 | 不開課說明與堂數退回 |

（一般狀況下，**預約成功不會另外通知管理員以外的第三人**；你的資料僅用於課程聯繫。）

---

## 十二、常見狀況快速對照

| 狀況 | 建議作法 |
|------|----------|
| 按預約卻說沒有堂數 | 先完成購課並等匯款確認 |
| 顯示備取 | 等候遞補；備取未遞補前不扣堂 |
| 已預約但沒收到開班通知 | 可能尚未過截止時間，或該堂未達 5 人；留意後續不開班通知 |
| 手機重複註冊 | 改用原 LINE 帳號，或確認手機號碼 |
| 想改預約時段 | 截止前取消再重約；截止後無法自行取消 |
| 不知道還有幾堂 | 會員資訊 → 剩餘堂數 |

---

## 十三、需要協助時

在 LINE 官方帳號 **直接傳訊息** 給工作室，說明姓名、預約日期或購課問題，我們會盡快回覆。

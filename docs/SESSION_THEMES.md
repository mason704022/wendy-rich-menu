# 課程主題維護指南

預約頁每個時段可顯示**標題**、**簡短介紹**、**示範小圖**。  
日常維護請使用 **管理後台 LIFF → 課程主題** 分頁，無需編輯程式或 JSON。

管理頁網址：`https://liff.line.me/{LIFF_ID}?page=admin`

---

## 更新各週課程（最常見）

**每一週**可設定不同主題；同一週的 **週三上午、週五晚間、週六上午** 共用相同標題、簡介與示範圖。

1. LINE 開啟管理頁 → 切到 **課程主題**
2. 在「選擇週次」下拉選單挑選要編輯的週（**本週起共五週**）
3. 修改標題、簡介
4. 若要換圖：點 **更換圖片** → 從相簿選圖
5. 點 **儲存此週課程**

若某週尚未設定，會沿用最近一週已設定的內容，直到您為該週儲存新主題。

「我要預約」以**後四週（28 天）**顯示可選時段；當新時段進入預約範圍時，會自動套用管理後台對應週次的標題、簡介與圖片。

---

## 新增單堂特別班

適用：母親節、節日、一次性特殊主題。

1. 管理後台 → **課程主題** → **新增特別班**
2. 選 **日期**、**時段**（週三/五/六對應時間）
3. 填標題、簡介
4. **上傳圖片** → **新增**
5. 僅該日期＋時段顯示特別主題；其餘仍用該週共用內容

---

## 編輯或刪除特別班

- 在「單堂特別主題」列表直接修改 → **儲存**
- 點 **刪除** → 該日恢復為該週共用課程

---

## 圖片建議

| 項目 | 建議 |
|------|------|
| 尺寸 | 正方形，至少 200×200 px |
| 格式 | JPG / PNG / WebP（手機相簿皆可） |
| 大小 | 原圖 ≤ 2 MB（系統會自動壓縮） |
| 內容 | 該堂課完成品或教學示意 |

---

## 仍需工程師協助的情況

| 需求 | 原因 |
|------|------|
| 新增全新上課時段（例如週四班） | 需改系統排程 `SLOT_TEMPLATES` |
| 正式環境上傳的圖在 redeploy 後消失 | 需將 `server/content/` 掛載到 Railway Volume |

---

## 技術參考（開發用）

- 資料檔：`server/content/session-themes.json`
- 圖片目錄：`server/content/images/sessions/`
- API：`/api/admin/session-themes/*`（需管理員 `ADMIN_LINE_USER_ID`）

```json
{
  "weeks": [
    {
      "weekStart": "2026-08-24",
      "title": "本週課程 · 水彩生活",
      "intro": "…",
      "image": "/content/images/sessions/weekly-default.svg"
    }
  ],
  "overrides": []
}
```

`weekStart` 為該週週一日期（`YYYY-MM-DD`）。舊版 `weekly` / `templates` 格式會在讀取時自動轉換。

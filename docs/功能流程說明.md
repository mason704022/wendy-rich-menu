# 藏在咖啡廳裡的畫畫課 — 系統功能流程說明

**文件版本：** 依程式庫 master（含會員註冊無簡訊 OTP、LINE ID 欄位、開班文案等）  
**更新日期：** 2026-11-08  
**正式網址範例：** https://wendy-rich-menu-production.up.railway.app

---

## 一、系統架構概覽

- **LINE 官方帳號**：Rich Menu 連結 LIFF 各頁；Webhook 接收 follow / 訊息等事件。  
- **LIFF 前端**：課程資訊、購買課程、預約上課、會員資訊；（管理員）後台。  
- **Express API**：預約、會員、購課、管理、Webhook。  
- **SQLite**：會員、購課、預約、折扣券、開班判定紀錄。  
- **Google Sheets（選用）**：會員註冊、預約、匯款同步。  
- **背景排程**：開班判定（每 5 分鐘）、課程主題缺漏提醒（每週）。

### Rich Menu 對應路徑（建議）

| 選單 | LIFF 路徑 |
|------|-----------|
| 課程資訊 | `/courses` |
| 購買課程 | `/purchase` |
| 預約上課 | `/booking` |
| 會員資訊 | `/member` |
| 管理後台 | `/admin`（僅管理員 LINE ID） |

## 二、學員端流程

### 2.1 加入好友

1. 使用者加入 LINE 官方帳號為好友。  
2. Webhook 收到 `follow` 事件。  
3. 系統以 **reply** 發送歡迎文（內容：`server/content/welcome-follow.json`）。  
4. **驗證方式：** LINE Developers Webhook Verify 成功；用測試帳號重新加好友應收到歡迎訊息。

### 2.2 會員註冊

**入口：** 購買課程、預約上課、會員資訊 — 未註冊時先顯示註冊表單。

| 欄位 | 說明 |
|------|------|
| LINE ID | 正式環境由 LIFF 自動帶入（唯讀），與登入帳號綁定 |
| 姓名 | 必填 |
| 年齡 / 職業 / 居住地 | 必填（含「其他」補充欄） |
| 手機 | 必填；**已移除簡訊驗證碼** |

**規則：**

- 同一手機不可重複註冊不同 LINE 帳號（409 重複註冊提示）。  
- 註冊成功後同步 Google Sheets「會員註冊」分頁（憑證就緒時）。  
- 刪除會員：正式環境 railway ssh 執行 `node server/dist/scripts/reset-member.js <LINE_ID>`。

### 2.3 購買課程

1. 瀏覽方案（`plans.json`：體驗 1 堂、五堂 3900、八堂 5900 等）。  
2. 閱讀購課條款（`purchase-terms.json`）。  
3. 可選用管理員指派的折扣券。  
4. 填寫匯款資訊（匯款人姓名、帳號後五碼等）→ 建立 **pending** 匯款單。  
5. **管理員**在後台確認 → 增加堂數、通知學員 LINE；拒絕則釋放券。  
6. 匯款資料同步 Google Sheets（若已設定）。

### 2.4 預約上課

**前置：** 已註冊且 `remaining_sessions > 0`（備取不扣堂，遞補為正取才扣）。

| 規則 | 數值 |
|------|------|
| 可預約日期範圍 | 今日起 **14** 天 |
| 每堂正取上限 | **10** 人 |
| 備取上限 | **2** 人 |
| 預約／取消截止 | 開課前 **24** 小時 |
| 開班門檻 | 截止後正取 **≥ 5** 人 |

**步驟：**

1. 選日期與時段（週三／週五／週六固定模板）。  
2. 閱讀訂課條款（`booking-terms.json`）。  
3. 檢視該週課程主題（後台維護）。  
4. 正取有名額 → **confirmed**，扣 1 堂；正取滿且備取未滿 → **waitlist**，不扣堂。  
5. 選飲品與冷熱（`coffee-menu.json`）。  
6. **預約成功 LINE 僅通知該學員**（不通知管理員）。  
7. 截止前可取消；正取取消退堂，並可能將備取遞補為正取。

### 2.5 開班／不開班（自動）

**時機：** 通過「開課前 24 小時」截止後，排程約每 5 分鐘對尚未判定的時段做一次判定（**非**第 5 人預約當下即通知）。

**滿 5 人（開班）：**

- **正取學員：** 開班確認（日期、時間、新竹回咖啡、前 20 分鐘入場、停車、個人飲品）。  
- **老師／回咖啡**（`DRINK_ORDER_LINE_USER_ID`，無則管理員）：預約人數與學員飲品統計。  
- **管理員：** 同上 staff 訊息。

**未滿 5 人（不開班）：**

- **所有預約學員：** 不開班說明、堂數歸還。  
- 系統取消該堂預約，正取退堂。  
- **老師／管理員：** 不開班摘要（含日期、時間、人數）。

### 2.6 會員資訊

- 檢視剩餘堂數、預約紀錄、可用折扣券。  
- 可編輯姓名、手機、個人資料（**變更手機無簡訊驗證**）。  
- 顯示 LINE ID。

## 三、管理員後台（`/admin`）

需環境變數 `ADMIN_LINE_USER_ID` 與請求帶同一 LINE User ID。

| 分頁 | 功能 |
|------|------|
| 待確認匯款 | 確認／拒絕購課、加堂或拒絕 |
| 預約名單 | 依週三／五／六檢視各堂正取、備取、飲品 |
| 課程主題 | 每週標題／介紹／圖片；單堂覆寫 |
| 折扣券 | 建立模板、指派會員（可 LINE 通知）、刪除模板／收回指派 |

**每週提醒：** 若 14 天窗口內某週缺課程主題，LINE 通知管理員（附後台連結）。

**診斷：** `GET /api/admin/check` 含 Google Sheets 是否可同步。

## 四、LINE 自動訊息一覽

| 觸發 | 對象 | 內容摘要 |
|------|------|----------|
| 加入好友 | 新好友 | 歡迎文（welcome-follow.json） |
| 預約成功 | 該學員 | 時段、正取/備取、飲品、開班說明 |
| 購課確認／拒絕 | 該學員 | 匯款結果 |
| 派券 | 該學員 | 折扣說明 |
| 截止後開班 | 正取學員、staff、管理員 | 見 2.5 |
| 截止後不開班 | 預約學員、staff、管理員 | 見 2.5 |
| 缺課程主題 | 管理員 | 每週提醒 |

## 六、流程圖（文字版）

### 6.1 學員主路徑

```
加入好友 → 歡迎訊息
    ↓
Rich Menu → 課程資訊 / 購買 / 預約 / 會員
    ↓
未註冊 → 註冊（LINE ID + 資料 + 手機）
    ↓
購課 → 匯款 pending → 管理員確認 → 有堂數
    ↓
預約 → 選時段與飲品 → 扣堂（正取）→ 預約成功通知（僅學員）
    ↓
開課前 24h 截止 → 系統判定 ≥5 人？
    ├─ 是 → 開班通知（學員 / 回咖啡 / 管理員）
    └─ 否 → 不開班、退堂、通知
```

### 6.2 預約名額邏輯

```
名額未滿 10 → 正取（扣堂）
正取滿且備取 < 2 → 備取（不扣堂）
備取滿 → 無法預約
開課前 24h 內 → 不可預約／不可取消
```

## 七、待確認項目（請勾選）

- [ ] 開班通知在「截止後」才發送，非滿 5 人即時。  
- [ ] 預約成功不通知管理員。  
- [ ] 註冊無簡訊 OTP，LINE ID 自動帶入。  
- [ ] 正取 10 / 備取 2 / 5 人開班 / 14 天窗口 / 24h 截止。  
- [ ] Google Sheets 正式環境憑證已設定。
